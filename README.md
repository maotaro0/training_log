# Traininglog

## アプリケーション概要

Traininglogは、筋トレの記録と過去の自分との比較を通して、自分の成長を実感しやすくするためのトレーニング記録アプリです。

## 利用方法

1. ユーザー登録、またはログインを行います。
2. トレーニングした種目・重量・回数・セット数・日付を記録します。
3. トップページから前回の記録を確認し、今回のトレーニング内容と比較します。
4. 成長グラフから、種目ごとの重量の推移を確認します。
5. 「今月のトレーニング回数 / 目標回数」を確認し、設定した月間目標に対する進捗を確認します。

記録したデータを残すだけではなく、過去の自分との比較を通して成長を確認し、次回のトレーニングにつなげることを目的としています。


## アプリケーションを作成した背景

筋トレを始めても、日々の変化は小さいため、「本当に成長しているのか分からない」と感じ、継続できなくなる人がいると考えました。

また、トレーニングを続けていると、

- 前回どのくらいの重量でトレーニングしたか分からない
- スマートフォンのメモなどから過去の記録を探すのが面倒
- 記録を残していても、数字だけでは成長に気づきにくい

といった課題があります。

そこで本アプリでは、トレーニング内容を簡単に記録し、過去の記録との比較やグラフによって成長を分かりやすくすることで、「自分は成長している」と実感できる体験を目指しました。

単に筋トレを記録するだけではなく、

**記録する → 成長を確認する → 成長を実感する → 継続につなげる**

という流れを意識して設計しています。


## 実装予定の機能

現在は、アプリケーションの中心となる機能を優先して実装しています。

今後は、以下の機能を段階的に追加する予定です。

- 前回のトレーニング内容をワンタップで入力できるコピー機能
- 前回記録との重量・回数の比較表示
- 自己ベスト更新時のハイライト表示
- トレーニング継続日数（ストリーク）の表示
- ユーザー独自のトレーニング種目登録機能
- 種目ごとの詳細な成長分析
- プロフィール画像の登録
- ゲストログイン機能
- トレーニング履歴の詳細表示・編集機能

まず最低限の機能を持つプロトタイプを完成させ、その後、実際の使いやすさを確認しながら必要な機能を追加していく方針です。

## 工夫したポイント

### 1. アプリの目的から逆算して機能を設計したこと

最初から多くの機能を追加するのではなく、

**「筋トレを継続するためには、自分の成長を実感できることが重要」**

という考えを出発点として機能を設計しました。

そのため、

**筋トレ記録 → 成長の可視化 → 成長の実感 → 継続**

という一連の体験になることを意識しています。


### 2. 過去の自分との比較を重視したこと

グラフを表示するだけではなく、

- 前回の記録
- 現在の記録
- 重量の変化
- 月間トレーニング回数

などを同じ画面で確認できるようにし、「どの部分が成長したのか」を分かりやすくすることを意識しました。


### 3. スマートフォンでの利用を前提にしたUI

ジムでスマートフォンから利用することを想定し、モバイルファーストで画面を設計しました。

トップページには、

- 今月のトレーニング回数
- 月間目標
- トレーニング記録への導線
- 成長情報
- 成長グラフ
- 前回の記録

など、利用頻度の高い情報をまとめています。

また、主要画面へ移動しやすいように、画面下部へ固定ナビゲーションを配置しています。


### 4. 最小構成から段階的に開発していること

最初からすべての機能を実装すると開発規模が大きくなるため、まずアプリの価値を確認できる最低限の機能に絞ってプロトタイプを作成しています。

まず、

**「記録できる」「過去と比較できる」「成長を確認できる」**

ところまでを完成させ、その後にストリークや自己ベスト判定などの機能を追加する方針としました。

機能を優先度ごとに整理し、動作する状態を維持しながら段階的に機能を追加することを意識しています。


## 改善点

現在はプロトタイプとして必要最低限の構成を優先しているため、今後はデータ構造や機能を拡張していきたいと考えています。

特に、現在はトレーニング記録をシンプルな構造で管理していますが、今後は、

- トレーニング単位
- 種目単位
- セット単位
- 部位単位

でデータを管理できるようにテーブル構成を見直すことで、より詳細な記録や分析を可能にしたいと考えています。

また、単純な重量の推移だけではなく、

- 前回から何kg増えたか
- 前回から何回増えたか
- 自己ベストを更新したか
- 一定期間でどのくらい成長したか

などを自動的に判定し、ユーザーがより成長を実感できる表示へ改善していきたいです。

さらに、実際に利用した際の操作性を確認し、入力項目や画面遷移を見直すことで、トレーニング中でも少ない操作で記録できるアプリを目指します。
